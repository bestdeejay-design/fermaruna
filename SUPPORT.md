# Support

## Where to get help

* **Website questions** (visiting the farm, products, orders): use the contact
  details published on the live site at http://fermaruna.ru.
* **Repository questions** (build, content, pull requests): open a
  [GitHub Issue](https://github.com/bestdeejay-design/fermaruna/issues) using
  the provided templates and describe what you tried.
* **Contributing**: read `CONTRIBUTING.md` first. The short version: edit
  `content/*.json`, run `python3 scripts/build.py`, commit the rebuilt HTML.

## Before opening an issue

1. Check existing issues to avoid duplicates.
2. State what you expected and what happened instead.
3. Include the page URL or file path, your browser or Python version, and
   steps to reproduce.

## Security matters

Do not open a public issue for vulnerabilities. Follow `SECURITY.md` and
report privately via GitHub Security Advisories.

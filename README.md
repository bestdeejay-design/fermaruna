# Ферма «Рунская» — сайт

Статический сайт натурального хозяйства «Рунская» (Тверская область, Пеновский округ, пос. Рунский).
Русский язык, без сборщиков и внешних зависимостей на проде: HTML + CSS + JS, шрифты и картинки лежат локально.

## Что внутри

| Путь | Назначение |
|---|---|
| `index.html` | Главная: преимущества, о ферме, метод, продукция, хроника, журнал, FAQ, форма заявки |
| `about/` | История и метод хозяйства |
| `news/` | Хроника сезона-2022 (8 записей с исходного сайта) |
| `articles/` | Журнал: библиотека с фильтром и поиском + 14 статей |
| `privacy/` | Политика конфиденциальности (152-ФЗ) |
| `404.html` | Страница ошибки |
| `send.php` | Обработчик формы (PHP 7.4+): ловушка от ботов, валидация, лимит частоты |
| `config.example.php` | Пример конфигурации получателя заявок |
| `sitemap.xml`, `robots.txt` | Индексация |
| `assets/` | Стили, скрипт, шрифты (Alegreya + Manrope, локально), WebP-иллюстрации, иконки |
| `content/` | Исходники контента: `site.json` (контакты), `news.json`, `faq.json`, `articles/*.json` |
| `templates/` | Шаблоны страниц |
| `scripts/build.py` | Генератор сайта (только стандартная библиотека Python) |

## Локальный просмотр

```bash
python3 -m http.server 4173
```

## Пересборка

```bash
python3 scripts/build.py
```

Канонический адрес по умолчанию — GitHub Pages. Для боевого домена:

```bash
SITE_BASE_URL=https://fermaruna.ru python3 scripts/build.py
```

Ссылки на страницах относительные, поэтому сайт одинаково работает в корне домена, в подпапке GitHub Pages и просто из файловой системы.

## Публикация на fermaruna.ru (хостинг sweb.ru, Apache + PHP)

1. Скопируйте в `public_html` содержимое корня репозитория, **кроме** `content/`, `templates/`, `scripts/`, `source-images/` (это исходники; от прямого доступа они также закрыты `.htaccess`).
2. Рядом с `send.php` создайте `config.php` по образцу `config.example.php` и впишите e-mail для заявок.
3. Когда на домене будет включён HTTPS, раскомментируйте редирект http→https в `.htaccess`.
4. Страница 404 уже подключена через `ErrorDocument`.

## Публикация на GitHub Pages

В настройках репозитория: Settings → Pages → Branch: `main` (или ветка с сайтом) → корень `/`.
Адрес предпросмотра указан в `scripts/build.py`; после смены адреса пересоберите сайт.

## Что заменить на боевые данные

- **Логотип.** Сейчас используется временный фирменный знак (`favicon.svg`, `assets/img/icon-*.png`, OG-обложка). Положите свой файл как `assets/img/logo.svg` (или `logo.png`/`logo.webp`) — шапка и подвал подхватят его автоматически при пересборке.
- **Телефон и e-mail.** Впишите в `content/site.json` (`phone`, `phone_display`, `email`) и пересоберите: они появятся в шапке, контактах, подвале и в обработчике формы.
- **Фотографии.** Иллюстрации в `assets/img/*.webp` — временные (сгенерированы). Замените файлы с теми же именами и ширинами (или своими) — разметка использует `srcset` из `assets/img/<имя>-<ширина>.webp`.
- **Реквизиты в `privacy/`** — дополните данными оператора при необходимости.

## Обработка персональных данных

Сайт не использует cookies и трекеры. Форма передаёт данные только в `send.php` (письмо на адрес из `config.php`); на сервере данные не сохраняются. Согласие на обработку (152-ФЗ) — обязательный чекбокс.

# Security Policy

## Supported Versions

The live site (http://fermaruna.ru) is served from the `main` branch.
Only the latest commit on `main` is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main (latest) | :white_check_mark: |
| Older commits | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for security matters.

* Preferred channel: [GitHub Security Advisories](https://github.com/bestdeejay-design/fermaruna/security/advisories/new)
  (private report to the maintainers).
* Alternative public-site contact: info@fermaruna.ru

We will acknowledge receipt, investigate, and follow up with a fix and
a public note as appropriate. Please allow reasonable time for remediation
before any public disclosure.
